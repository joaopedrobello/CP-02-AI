# 🧠 Tradutor de Mídia com Visão Computacional
Projeto desenvolvido para a Yan Technology com o objetivo de traduzir textos capturados por webcam ou vídeo, usando técnicas de visão computacional e tradução automática.

## 🎯 Objetivo
Permitir a tradução rápida e prática de textos físicos como rótulos, anotações, placas, entre outros, para o português.

## 🛠️ Tecnologias Utilizadas
* Python
* OpenCV
* EasyOCR
* Deep Translator (Google Translate)

## ▶️ Como Executar
1. Instale as dependências:
```bash
pip install opencv-python easyocr deep-translator
```

## Problemas!
Caso ocorra um problema na hora de executar e o OpenCV não reconheça alguns comandos, teste isso
```bash
pip uninstall opencv-python-headless -y

pip install opencv-python --upgrade
```
